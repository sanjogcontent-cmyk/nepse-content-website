# NEPSE Content Website

Daily NEPSE order-flow content website for market story, stock pages, sector pages, boards, and video-ready analysis.

## Frontend

The public website is inside the frontend folder.

## Local run

cd frontend
npm install
npm run dev

## Production build

cd frontend
npm run build

## Cloudflare Pages settings

Root directory: frontend
Build command: npm run build
Build output directory: dist
Production branch: main
